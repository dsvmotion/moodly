El motor

Un mismo recorrido para cada tarea. De la entrada al registro.

01

Entrada

Un mensaje, un evento o un objetivo abre la tarea.

02

Contexto

Reúne conocimiento, memoria y datos del negocio.

03

Decisión

Las reglas dicen si puede actuar o pide aprobación.

04

Acción

Ejecuta en la herramienta real, una sola vez.

05

Registro

Queda qué hizo, por qué y cuánto costó.

Qué es un agente

Modelo + conocimiento + memoria + objetivos + skills + integraciones + reglas + permisos

Cuatro niveles de autonomía

Sugiere · redacta · ejecuta · autónomo, con un techo según el efecto de cada acción

El punto para un inversor: el recorrido es el mismo para cualquier agente y cualquier sector. Lo que cambia es la configuración. El techo de autonomía significa que una acción con dinero o con datos sensibles nunca pasa de cierto nivel sin una persona.
